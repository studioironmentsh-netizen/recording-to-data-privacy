# SPK-META-01 — תוכנית בדיקות

## מגבלות Meta שנבדקו (קישורים ב-RESULTS)
- Reply buttons: עד **3** כפתורים; כותרת כפתור עד **20** תווים; גוף עד **1024** תווים; id של כפתור עד 256 תווים.
- הודעה אינטראקטיבית חופשית (לא Template) נשלחת רק **בתוך חלון שירות של 24 שעות** מההודעה האחרונה של המשתמש. מחוץ לחלון: Template עם Quick Reply.
- לחיצה מגיעה ב-webhook כ-`messages[].type = "interactive"`, `interactive.type = "button_reply"` עם `id`+`title`, ו-`context.id` = מזהה ההודעה המקורית.
- הודעת קול: `type = "audio"`, `audio.id`, `mime_type` (ogg/opus), `voice: true`. ה-URL להורדה תקף **~5 דקות**, הורדה עם Bearer token; ה-media id זמין כ-7 ימים.
- חתימה: `X-Hub-Signature-256: sha256=<HMAC-SHA256(raw body, App Secret)>`.
- שליחה לטלפון בסביבת DEV: רק למספרים שנוספו כנמענים ב-Meta.

## בדיקות חיות (שער קבלה)
### META-01 — הודעה קולית
- **תנאים מוקדמים:** שרת רץ, HTTPS ציבורי, Webhook מאומת ב-Meta, שדה `messages` מנוי, מספר הטכנאי ב-allowlist.
- **פעולות:** הטכנאי שולח הודעת קול ל-WhatsApp של Meta.
- **צפוי:** POST נחתם ותקין, מזוהה `audio`, המדיה מורדת, sha256 תואם, גודל>0, הקובץ נמחק; לוג ללא תוכן.
- **כשל:** חתימה נכשלת; אין event; 401/403 בהורדה (טוקן); URL פג; sha256 לא תואם.
- **ראיות:** שורות לוג מוסתרות (message id מקוצר, mime, size, sha256 קצר, status); צילום מסך ללא תוכן רגיש.
- **מצב:** NOT RUN

### META-02 — כפתורים
- **תנאים מוקדמים:** META-01 הצליח לפחות ברמת חיבור; חלון 24 שעות פתוח (הטכנאי שלח הודעה בשעה האחרונה).
- **פעולות:** `send-form` שולח טופס ניסיוני; לוחצים "אשר"; שולחים טופס נוסף ולוחצים "תקן או הוסף".
- **צפוי:** שליחה מחזירה wamid; כל לחיצה מתקבלת ומזוהה כ-approve/edit.
- **כשל:** שגיאת Graph (חלון סגור, הרשאה); אין webhook ללחיצה; כותרת מעל 20 תווים.
- **ראיות:** לוג `button_click` עם action, form_id, revision; צילום הטלפון.
- **מצב:** NOT RUN

### META-03 — שיוך לטופס
- **תנאים מוקדמים:** META-02 עובד.
- **פעולות:** שולחים טיוטה A rev1 וטיוטה B rev1; לוחצים על B ואז על A (שלא בסדר השליחה). שולחים A rev2 ולוחצים על הכפתור הישן של A rev1.
- **צפוי:** כל לחיצה משויכת לטופס/גרסה הנכונים; לחיצה על A rev1 לאחר עדכון → נדחית כישנה, ללא שינוי מצב.
- **כשל:** שיוך לטופס שגוי; עיבוד לחיצה ישנה; context.id חסר ב-webhook.
- **ראיות:** לוגים + קובץ state (ללא תוכן רגיש) + צילום.
- **מצב:** NOT RUN

# כללי פרויקט (PROJECT_RULES)

1. **ענף:** עבודה רק ב-`spike/meta-whatsapp`. ללא Push/Merge/שינוי `main` ללא הוראה מפורשת.
2. **סודות:** טוקנים, App Secret ו-Verify Token רק ב-`.env` מקומי (מוחרג מ-Git). לעולם לא בצ'אט, בלוגים, בקוד או בדוחות.
3. **פרטיות:** אין הקלטות, מספרי טלפון מלאים או נתוני לקוחות אמיתיים ב-Git/לוגים. מספרים מוסתרים (`***123`).
4. **ללא ייצור:** אין פריסה, אין שירות בתשלום ללא אישור מפעילה.
5. **Scope:** ניסוי היתכנות Meta בלבד. אין AI, תמלול, ממשק מנהל או Multi-Tenant מלא.
6. **גנריות:** טכנאים ומזהי טפסים מוגדרים בקונפיגורציה/נתונים, לא מקודדים בלוגיקה.
7. **אמינות תוצאות:** PASS רק על בסיס בדיקה חיה אמיתית. Mock = לכל היותר "PASS (mock)" ולא נחשב PASS. חוסר גישה = BLOCKED/NOT RUN.
8. **תלויות:** גרסאות נעולות (exact). תלויות מינימליות בלבד.
9. **Commits:** מקומיים, ממוקדים, הודעות ברורות.
10. **כלל עצירה:** כשל בבדיקה חיה → עצירה, תיעוד והמלצת תיקון לפני המשך.

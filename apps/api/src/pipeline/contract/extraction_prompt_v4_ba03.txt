STATES (evidence_state per field):

- MISSING: not mentioned. value null.
- UNKNOWN: (VAT fields only, and only for "not said") value "UNKNOWN".
- UNCLEAR: something was said but cannot be extracted safely (an unclear word, two different values without a correction, an amount whose owner is unclear, a word you would have to interpret from context). value null (VAT: "UNKNOWN"); needs_clarification true.
- NOT_DECIDED: the technician said the matter is not decided yet (e.g. "the price I still need to close"). value null.
- NEEDS_CONFIRMATION: a value was said but its link/meaning is ambiguous (e.g. a weekday without a date). value may be set; needs_clarification true.
needs_clarification is true exactly for UNCLEAR and NEEDS_CONFIRMATION, otherwise false. Every field with needs_clarification true needs one clarification_requests entry (field_keys, reason_code in AMBIGUOUS_REFERENCE|UNCLEAR_AUDIO|UNKNOWN_VALUE|NEEDS_CONFIRMATION|NOT_DECIDED, candidate or null).
